# Changelog

All notable changes to Heartline. Each release's notes are written by the Build workflow when the
release is made, and the app shows them under *What's new* after an update.

## 0.0.2.106-beta.1 — 2026-09-28

### New
- Help & diagnostics: export the phone's and the watch's logs as two files
- Update channels: Stable, Beta and Development (Settings → Updates → Update channel)
- Links to the source code and the Heartline community on Telegram in Settings and About

### Improved
- Blood pressure algorithm 6: uses every watch sensor, with full raw session logs
- Blood pressure algorithm 6.1: fixes from the first real Galaxy Watch8 Classic logs
- Development builds update to betas and releases without reinstalling
- Settings shows whether you're on a beta or development build next to the version
- Documentation, terms and policy updates
