# CLA signatures

This branch only stores the contributor signatures for the [Contributor License Agreement](https://github.com/Selin2005/Heartline/blob/main/CLA.md).

The CLA workflow (`.github/workflows/cla.yml` on `main`) writes `signatures/cla.json` here when a
pull request author signs. Don't edit it by hand, and don't merge this branch into `main`.
